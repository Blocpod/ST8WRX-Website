01 / The missing layer

The workspace was only half the system.

Collaboration platforms can show what happened. ST8WRX is designed to carry that work forward into evidence, attribution, contribution state, compute receipts, and verifiable settlement.

That changes the primitive. A message is no longer just a message. A commit, decision, agent result, or compute job can become part of a provable project history.
